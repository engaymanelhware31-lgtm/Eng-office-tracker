# نظام متابعة العملاء والمعاملات الهندسية — نسخة محلية

## تحديث المستودع
1. فك ضغط هذه الحزمة.
2. افتح مستودع `Eng-office-tracker` على GitHub.
3. اختر `Add file` ثم `Upload files`.
4. ارفع `index.html` و`README.md` ثم اضغط `Commit changes`.
5. انتظر تحديث GitHub Pages ثم أعد تحميل الموقع.

## الوظائف
- صفحات العملاء والمعاملات والمشروعات والمهام والتقارير.
- إضافة وتعديل وحذف السجلات.
- بحث وتصفية المعاملات والعملاء.
- تقرير قابل للطباعة، وتصدير CSV، ونسخة احتياطية JSON واستعادتها.
- حفظ محلي في متصفح الجهاز.

## حدود مهمة
البيانات تحفظ في `localStorage` ولا تتزامن بين الأجهزة. قد تضيع إذا مسحت بيانات الموقع أو استخدمت نافذة خاصة. صدّر نسخة احتياطية بانتظام. لا يوجد تسجيل دخول أو حماية متعددة المستخدمين في هذا الإصدار؛ لا تستخدمه على جهاز مشترك أو لبيانات شديدة الحساسية.
