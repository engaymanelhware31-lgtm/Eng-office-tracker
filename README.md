# نظام متابعة العملاء والمعاملات للمكاتب الهندسية

واجهة عربية (RTL) متجاوبة للكمبيوتر والجوال، معدّة للنشر كصفحة GitHub Pages.

## محتويات المشروع
- `index.html`: واجهة تجريبية للوحة التحكم وقائمة المعاملات والبحث والتصفية.
- `schema.sql`: مخطط أولي لقاعدة بيانات PostgreSQL.

## نشر الواجهة على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub، مثل `engineering-office-tracker`.
2. ارفع الملفين `index.html` و`schema.sql` إلى المجلد الرئيسي للمستودع.
3. افتح `Settings` ثم `Pages`.
4. في `Build and deployment` اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط `Save`.
6. انتظر اكتمال النشر، ثم افتح الرابط الذي يظهر في صفحة Pages.

## تنبيه مهم
النسخة الحالية **واجهة تجريبية فقط**:
- تعرض بيانات توضيحية داخل الصفحة.
- لا تحفظ المعاملات في قاعدة بيانات.
- لا تحتوي على تسجيل دخول فعلي أو نظام صلاحيات.
- ملف `schema.sql` مخطط مبدئي، وليس قاعدة بيانات مستضافة أو متصلة بالواجهة.

GitHub Pages يستضيف ملفات الواجهة الثابتة فقط. لتشغيل النظام التجاري لعدة مكاتب مع حسابات مستخدمين وعزل آمن للبيانات، يجب إضافة خادم خلفي وقاعدة بيانات مستضافة، وتطبيق سياسات عزل البيانات واختبارها قبل إدخال بيانات حقيقية.

لا ترفع بيانات عملاء حقيقية أو كلمات مرور أو مفاتيح سرية إلى مستودع GitHub عام.
